# Sintesis de Grafo

1. Identifica notas centrales con mayor numero de backlinks y conexiones salientes.
2. Detecta notas huerfanas o desconectadas y propone enlaces `[[nota]]` respaldados por similitud semantica.
3. Consolida etiquetas `#tema` consistentes para agrupar conocimiento por dominio.
4. Resume rutas conceptuales entre dos notas citando los enlaces intermedios exactos.
5. Mantiene referencias precisas al ID de cada nota al redactar conclusiones.
